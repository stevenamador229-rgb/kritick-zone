# KRITICK THE ZONE — public menu

This folder is a static, public menu for GitHub Pages. It has only public
prices, pay links, the ZONE inbox, and the same cards as the printed menu.
It does not include customer data, orders, or private Studio settings.

Live URL (after Pages is on):
https://stevenamador229-rgb.github.io/kritick-zone/

## Publish these files (one-time)

1. Open https://github.com/new
2. Repository name: `kritick-zone`
3. Set it to **Public**. Leave “Add a README” unchecked.
4. Click **Create repository**.
5. On the empty repo page, click **uploading an existing file**.
6. Drag every file and folder in *this* directory (`index.html`, `css/`, `js/`, `img/`, `README.md`) into the browser. Commit.
7. Open the repo **Settings** tab → **Pages**.
8. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
9. Branch: **main**, folder: **/ (root)**. Click **Save**.
10. Wait a minute, then open https://stevenamador229-rgb.github.io/kritick-zone/

## Update after you tap Publish menu in Studio

Repeat step 5–6 with the newly generated files (or `git add/commit/push` if you cloned the repo). Pages will refresh on its own.
